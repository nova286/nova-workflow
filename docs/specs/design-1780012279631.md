# Design: 多平台支持

## Architecture Overview

Nova 的平台适配采用 **Strategy Pattern**，通过两个接口隔离平台差异：

```
┌─────────────────────────────────────────────────┐
│                  Dispatcher                      │
│  (consumes PlatformClient, agnostic to platform) │
└──────────────┬──────────────────────────────────┘
               │
       ┌───────┴───────┐
       │ PlatformClient │  ← abstract: sendPrompt()
       └───────┬───────┘
               │
   ┌───────────┼───────────┬───────────┬───────────┐
   │           │           │           │           │
ClaudeCode  CodexClient  OpenClaw   HermesAgent  OpenCode
  Client                                         Client
```

```
┌──────────────────────────────────────┐
│           InitManager                │
│  detectAIEnvironment() → string[]    │
│  getAdapter(env) → EnvironmentAdapter│
└──────────────┬───────────────────────┘
               │
       ┌───────┴────────┐
       │EnvironmentAdapter│  ← interface: name, setup(cwd)
       └───────┬────────┘
               │
   ┌───────────┼───────────┬───────────┬───────────┐
   │           │           │           │           │
ClaudeCode  CodexAdapter OpenClaw   HermesAgent  OpenCode
  Adapter                             Adapter    Adapter
```

**关键设计决策：**
- `PlatformClient` 负责 CLI 调用（spawn + 解析输出）
- `EnvironmentAdapter` 负责文件生成（skill/command 文件）
- 两者解耦：一个平台可以有 Client 但没有 Adapter（降级模式）
- `resolvePlatformClient` 是唯一工厂入口，从 `.nova.yaml` 的 `environment` 字段路由

## Tech Stack

| 技术 | 用途 | 理由 |
|------|------|------|
| TypeScript 5.x | 实现语言 | 项目已有，strict 模式 |
| Node.js child_process | CLI spawn | 各平台 Client 统一使用 |
| Jest 29 | 测试 | 项目已有 |
| Commander | CLI 框架 | 项目已有 |

无新增外部依赖。所有平台适配通过 Node.js 内置模块实现。

## Component Breakdown

### 1. PlatformClient 子类

每个子类实现 `sendPrompt(prompt, options) → PlatformResponse`。

**ClaudeCodeClient**（已有，参考实现）：
- spawn `claude --model <model> --print --effort <effort> --no-session-persistence --allowedTools Read`
- 通过 stdin 传入 prompt
- stdout 为纯文本输出

**CodexClient**（新增）：
- spawn `codex --quiet`（或等效的非交互模式）
- 通过 stdin 或 `--prompt` 参数传入
- 需调研：是否有 `--print` 等效模式、model 选择方式

**OpenClawClient**（新增）：
- spawn `openclaw` CLI
- 需调研：CLI 参数、输出格式、是否有非交互模式

**HermesAgentClient**（新增）：
- spawn `hermes-agent` CLI
- 需调研：CLI 参数、输出格式

**OpenCodeClient**（新增）：
- spawn `opencode` CLI
- 需调研：CLI 参数、输出格式

### 2. EnvironmentAdapter 实现

每个适配器实现 `setup(cwd)` — 在项目目录下生成平台特定的 skill 文件。

**ClaudeCodeAdapter**（已有，参考实现）：
- 生成 `.claude/commands/*.md`（7 个 skill 文件）

**CodexAdapter**（新增）：
- 生成 Codex 兼容的 instruction 文件
- 需调研：Codex 的 AGENTS.md / instructions 格式

**OpenClawAdapter**（新增）：
- 需调研：OpenClaw 的 skill/command 文件格式

**HermesAgentAdapter**（新增）：
- 需调研：Hermes Agent 的配置格式

**OpenCodeAdapter**（新增）：
- 需调研：OpenCode 的配置格式

### 3. 平台检测（InitManager）

**detectAIEnvironment()** 改造：

```typescript
private async detectAIEnvironment(): Promise<string[]> {
  const detectors = [
    { env: 'claude-code', check: () => this.commandExists('claude') },
    { env: 'codex', check: () => this.commandExists('codex') },
    { env: 'openclaw', check: () => this.commandExists('openclaw') },
    { env: 'hermes-agent', check: () => this.commandExists('hermes-agent') },
    { env: 'opencode', check: () => this.commandExists('opencode') },
  ];
  const detected: string[] = [];
  for (const d of detectors) {
    if (await d.check()) detected.push(d.env);
  }
  return detected.length > 0 ? detected : ['claude-code']; // fallback
}
```

**getAdapter()** 改造为工厂：

```typescript
private getAdapter(env: string): EnvironmentAdapter {
  const adapters: Record<string, () => EnvironmentAdapter> = {
    'claude-code': () => new ClaudeCodeAdapter(),
    'codex': () => new CodexAdapter(),
    'openclaw': () => new OpenClawAdapter(),
    'hermes-agent': () => new HermesAgentAdapter(),
    'opencode': () => new OpenCodeAdapter(),
  };
  const factory = adapters[env];
  if (!factory) throw new Error(`Unknown environment: ${env}`);
  return factory();
}
```

### 4. resolvePlatformClient 改造

```typescript
export async function resolvePlatformClient(cwd?: string): Promise<PlatformClient> {
  const dir = cwd ?? process.cwd();
  try {
    const raw = await fs.readFile(path.join(dir, '.nova.yaml'), 'utf-8');
    const state = yaml.parse(raw) as { environment?: string[] };
    const env = state.environment?.[0];

    const clients: Record<string, () => PlatformClient> = {
      'claude-code': () => new ClaudeCodeClient(),
      'codex': () => new CodexClient(),
      'openclaw': () => new OpenClawClient(),
      'hermes-agent': () => new HermesAgentClient(),
      'opencode': () => new OpenCodeClient(),
    };

    const factory = clients[env ?? 'claude-code'];
    if (!factory) throw new Error(`Unsupported environment: ${env}`);
    return factory();
  } catch (err: any) {
    if (err.message?.includes('Unsupported')) throw err;
  }
  return new ClaudeCodeClient();
}
```

## Data Flow

```
nova init
  → detectAIEnvironment() → ['claude-code', 'codex']
  → getAdapter('claude-code').setup() → .claude/commands/*.md
  → getAdapter('codex').setup() → codex instructions
  → generateConfig(['claude-code', 'codex']) → .nova.yaml

/nova-implement (inside session)
  → read .nova.yaml → environment: ['claude-code']
  → resolvePlatformClient() → ClaudeCodeClient
  → dispatcher.execute(task) → client.sendPrompt() → spawn claude

/nova-implement (Codex user)
  → read .nova.yaml → environment: ['codex']
  → resolvePlatformClient() → CodexClient
  → dispatcher.execute(task) → client.sendPrompt() → spawn codex
```

## Risks & Mitigations

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 各平台 CLI 接口文档不全 | 实现可能不准确 | task `research-platform-clis` 先行，产出调研文档；实现时标注已知限制 |
| 部分平台无非交互模式 | 无法通过 stdin 传 prompt | 调研替代方案：临时文件、环境变量、子命令 |
| 平台 skill 文件格式未知 | Adapter 可能生成无效文件 | 先实现最小可用版本，标注为 experimental |
| spawn 行为跨平台差异 | Windows 兼容性问题 | 使用 `cross-spawn` 或统一用 `shell: true`；当前仅支持 macOS/Linux |
| 测试需要各平台 CLI 安装 | CI 环境可能缺少工具 | Mock spawn + 标注集成测试为 manual |
